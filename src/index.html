What gets closed while a watched game is running

Processes below are force-closed while your game is running. Nothing is reopened afterwards — that's on purpose.

Windows tweaks — per boost

Optional tweaks applied while a watched game is boosting and reverted when it exits. Items marked shield need Slipstream running as admin — if it isn't, they're greyed out and toggling requests elevation.

Windows tweaks — once (permanent)

One-time tweaks applied to the machine and tracked in store.json; each shows an "Applied" state and an explicit Revert button. Several need a reboot.

Debug

The debug console is its own small OS window (toa.sh) showing every log line live. Toggle it any time with F12 or Ctrl+` — it starts closed. Debug logging is off by default; enable it when you need to capture what's happening.
